# Credit Scoring: ทำนายโอกาสผิดนัดชำระหนี้ (German Credit)

โปรเจกต์สร้างโมเดลทำนายความน่าจะเป็นที่ผู้กู้จะผิดนัดชำระหนี้ (Probability of Default) ด้วย Logistic Regression อธิบายว่าปัจจัยใดมีผลต่อความเสี่ยง และวิเคราะห์ผลทางธุรกิจจากการกำหนดเกณฑ์อนุมัติสินเชื่อ

**เครื่องมือ:** SQL, Python (pandas, scikit-learn, matplotlib), Excel

---

## 1. เป้าหมาย

1. สร้างโมเดลที่ประเมินโอกาสผิดนัดชำระของผู้กู้แต่ละราย
2. อธิบายได้ว่าตัวแปรใดเพิ่มหรือลดความเสี่ยง
3. เลือกเกณฑ์อนุมัติ (threshold) และสรุปผลกระทบต่อ approval rate และสัดส่วนหนี้เสีย

## 2. ชุดข้อมูล

**German Credit Data** จาก UCI Machine Learning Repository
- ประมาณ 1,000 แถว 20 ตัวแปร
- ตัวแปรเป้าหมาย: ผู้กู้เป็น good หรือ bad credit risk
- ตัวอย่างตัวแปร: อายุ, จำนวนเงินกู้, ระยะเวลากู้, วัตถุประสงค์การกู้, สถานะบัญชีออมทรัพย์/เงินฝาก, ประวัติเครดิต

## 3. ขั้นตอนการทำงาน

### ขั้นที่ 1: สำรวจข้อมูลด้วย SQL
- โหลดข้อมูลเข้าฐานข้อมูล (เช่น SQLite)
- หา default rate แยกตามกลุ่มอายุ, วัตถุประสงค์การกู้, ประวัติเครดิต, ช่วงวงเงินกู้
- ตรวจ missing values และค่าผิดปกติ

### ขั้นที่ 2: เตรียมข้อมูลด้วย Python
- แปลงตัวแปรหมวดหมู่เป็นตัวเลข (one-hot encoding)
- แบ่งข้อมูล train/test (เช่น 70/30) โดยใช้ `stratify` เพื่อรักษาสัดส่วน good/bad

### ขั้นที่ 3: สร้างโมเดล
- ฝึก Logistic Regression ด้วย scikit-learn
- ดูค่า coefficient เพื่ออธิบายว่าตัวแปรใดเพิ่มหรือลดโอกาสผิดนัด

### ขั้นที่ 4: ประเมินผล
- AUC-ROC: ความสามารถในการแยกผู้กู้ดีออกจากผู้กู้เสี่ยง
- KS Statistic: ระยะห่างสูงสุดระหว่างการกระจายของ good และ bad
- Confusion Matrix ที่ threshold ต่างๆ

### ขั้นที่ 5: วิเคราะห์เชิงธุรกิจด้วย Excel
- ทดลอง threshold หลายระดับ เช่น 0.2, 0.3, 0.4, 0.5
- สร้างตารางสรุป: approval rate, bad rate ของกลุ่มที่อนุมัติ, จำนวนผู้กู้ที่ถูกปฏิเสธ
- (ทางเลือก) ตั้งสมมติฐานต้นทุน เช่น อนุมัติคนผิดนัด 1 ราย เสียหายเท่ากับกำไรจากผู้กู้ดีกี่ราย แล้วหา threshold ที่เหมาะสม
- ทำกราฟสรุปและเขียนข้อเสนอแนะ

## 8. ข้อจำกัดของโปรเจกต์

- ข้อมูลมีขนาดเล็ก (~1,000 แถว) ผลอาจไม่เสถียรเท่าข้อมูลจริง
- ไม่มีข้อมูลของผู้กู้ที่ถูกปฏิเสธในอดีต (reject inference)
- เป็นข้อมูลเก่า อาจไม่สะท้อนพฤติกรรมผู้กู้ปัจจุบัน
- ยังไม่ได้ตรวจเรื่องความเป็นธรรมของโมเดลต่อกลุ่มต่างๆ

## 9. แผนต่อยอด

- เพิ่ม WoE/IV เพื่อคัดเลือกตัวแปร
- เปรียบเทียบกับ Random Forest หรือ XGBoost
- ลองกับชุดข้อมูล Give Me Some Credit (Kaggle)
- แปลงโมเดลเป็น scorecard

## แผนการทำงาน 3 สัปดาห์

| สัปดาห์ | สิ่งที่ทำ | เป้าหมาย |
|---|---|---|
| 1 | เรียนรู้พื้นฐาน credit risk (PD, good/bad, default) และทำ EDA ด้วย SQL | เข้าใจข้อมูล และมีตาราง default rate แยกกลุ่มอย่างน้อย 4-5 มุมมอง |
| 2 | เตรียมข้อมูล สร้าง Logistic Regression วัด AUC/KS อ่าน coefficient | มีโมเดลที่รันได้ และอธิบายตัวแปรสำคัญได้ |
| 3 | ทำ threshold analysis ใน Excel เขียนสรุปผล เก็บ README ให้ครบ และซ้อมตอบคำถาม | โปรเจกต์พร้อมยื่น และอธิบายได้ภายใน 2-3 นาที |

**ถ้ามีเวลาเหลือ** ให้ทำหัวข้อ "แผนต่อยอด" สัก 1 ข้อ เช่น เทียบกับ Random Forest จะช่วยให้ตอบคำถามเรื่องการเลือกโมเดลได้ดีขึ้น
